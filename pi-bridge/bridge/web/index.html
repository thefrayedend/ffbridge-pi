Welcome! Let's connect your printer.

This board turns your FlashForge printer into something Mainsail and OrcaSlicer understand, and can watch your prints with AI. It only takes a minute.

Add my printer

Send prints from OrcaSlicer

  1. In OrcaSlicer, click the Wi-Fi icon next to your printer (Connection settings).
  2. Host type: Octo/Klipper
  3. Hostname, IP or URL: this-board:7125  
    If your router gives the board a new address one day, ffbridge.local:7125 keeps working too.
  4. Leave the API key empty and press Test. The Device tab now shows Mainsail.

Printers

Before you start: turn on LAN-only mode on the printer
  1. On the printer's touch screen open Settings → Network (Wi-Fi or Ethernet).
  2. Turn on LAN-only mode. The printer now shows an 8-character pairing code (also called check code).
  3. Keep that screen open, then press Scan network here.

Supported: Creator 5 / 5 Pro, AD5X, Adventurer 5M / 5M Pro. The printer and this board must be on the same home network.

Your printers

AI failure detection

While a print runs, the board looks at the printer camera every few seconds with an open-source AI model (from Obico) that recognises "spaghetti" and other failures. Nothing leaves your network.

When it sees a likely failure
Sensitivity
"High" catches problems sooner but may raise more false alarms.

Alerts appear here, as a pop-up in Mainsail, and in Discord if you set it up under Settings.

Discord notifications

Multi-colour prints (AD5X / Creator 5)

When a multi-colour .3mf is sent through the bridge (OrcaSlicer "Print" or Mainsail), each slicer filament is matched to the loaded spool with the same material and closest colour.

"Ask" opens a pop-up in Mainsail (and in OrcaSlicer's Device tab) with a button per slot for each filament, then Start print.

Spoolman

Mainsail then shows the Spoolman panel and filament use is deducted from the active spool when a print ends.
